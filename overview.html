2026 Congressional App Challenge Entry

Screen time that
turns into fitness.

Privacy-first fitness app that uses on-device AI to count repetitions in real time. No video ever leaves your device as cloud sync is optional and stores only a username and your XP. Gamified with XP, ranks, and streaks so that you can compete against your friends!

Try Live Demo GitHub

Fully open sourced under the Apache-2.0 license.

Our inspiration came from our own screen time reports — easily 6+ hours a day. We didn't want to cut out the screen. We wanted to use it to grow ourselves.

Then we learned we weren't alone. Over half of US teens spend 4+ hours daily on screens,3 and since 1990, adolescent steps have dropped by almost 30%.1

Teens love games, but most fitness apps don't make staying active fun. So we built RepQuest: a simple, intuitive app that works on almost any device, turning screen time into fitness time. Rep counting and XP run entirely on-device;2 cloud sync is optional and stores only a username and XP.

repquest — privacy
$ repquest --privacy
// Processing video locally...
// Counting reps: 12, 13, 14...
// Video never leaves this device. ✓
// Cloud sync optional — username + password only.
